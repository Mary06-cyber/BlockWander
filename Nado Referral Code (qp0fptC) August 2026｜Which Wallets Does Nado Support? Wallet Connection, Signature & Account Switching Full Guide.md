On first connection, you may see a Signature request.

Standard login signatures are used to:

- Prove wallet ownership.
- Establish login authentication.
- Link your Web3 account.

A normal login signature:

- Does not transfer assets.
- Does not ask for your seed phrase.
- Usually does not require Gas.

Immediately stop any interaction if a site asks for:

- Seed Phrase / Mnemonic
- Private Key
- Google Authenticator code
- Full wallet backup files

## 🔄 How to Switch Wallets or Accounts on Nado?

If you have multiple wallets on the same device, switch as follows:

1. Disconnect your current Nado session.
2. Open your wallet extension or app.
3. Switch to another wallet account.
4. Return to Nado.
5. Click **Connect Wallet** again.
6. Confirm the new address.

Different wallet addresses represent different Web3 identities.

Example:

- Wallet A: Main trading account
- Wallet B: Testing new protocols
- Wallet C: Long-term asset storage

Avoid keeping large amounts of funds in hot wallets frequently connected to unknown dApps.
