## 11. 📊 Maker vs Taker: Why Your Fee Can Be Different

Bybit spot fees depend on whether your order is classified as Maker or Taker.

| Order Behavior | Typical Classification | What Happens |
|----------------|----------------------|--------------|
| Limit order stays in order book | Maker | Adds liquidity |
| Market order executes immediately | Taker | Removes liquidity |
| Limit order executes immediately | Taker | Does not remain on book |
| Post-Only limit order | Maker if accepted | Designed to avoid immediate taker execution |

A common mistake is thinking:

> Limit Order = Maker

That is not always true.

If your limit order crosses the order book and executes immediately, it can still be treated as a Taker order.

Check the actual filled-order record.
